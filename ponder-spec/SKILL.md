# Ponder Specifications
Recursively perform the following tasks to ponder the specifications:
- Read the specification file.
- Identify gap of specifications.
- Identify overlap of specifications.
- Identify inconsistency of specifications.
- Identify any ambiguities or unclear points within those steps.
- Identify open questions of specifications.
- Use AskUserQuestion to clarify any points of uncertainty.


# Instructions
1. Read the target files using the Read tool.
2. Search for specific patterns using Grep.
3. Find related files using Glob
4. Ask any ambiguities using AskUserQuestion.
